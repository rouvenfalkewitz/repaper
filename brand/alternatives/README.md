# Brand direction alternatives

Three candidate directions for the RePaper identity. Pick one; the others get deleted and the winner becomes `brand/`.

| | A · E-paper (current `brand/`) | B · Industrial | C · Stationery |
|---|---|---|---|
| **Feel** | The product itself: matte, flat, high-contrast, a bit playful | Shop floor: label printers, safety signage, stencils | A good desk: soft serif, fountain-pen ink, real paper |
| **Who it speaks to first** | Tech-savvy buyers, both B2B and consumer | Logistics / manufacturing / lab buyers | Office, hospitality, consumer |
| **Ground / ink** | Panel grey `#EFF1EE` / `#131614` | Chalk `#EEF0F3` / Steel `#161C26` | Cotton `#FBF8F3` / Umber `#231F1A` |
| **Accent** | Re Green `#14A37F` | Safety Orange `#E8590C` | Ink Blue `#2447C9` |
| **Display type** | Bricolage Grotesque | Archivo (wide + condensed, caps) | Fraunces (soft, wonky) |
| **Body / mono** | Figtree / IBM Plex Mono | Source Sans 3 / JetBrains Mono | Albert Sans / Courier Prime |
| **Shape** | Radius 4/6/12, hairlines, no shadows | Square, 2 px frames, dashed tear lines | Radius 3/8/16, pills, soft paper shadows |
| **Motif** | 1-bit dither, e-ink refresh flash | Label with tear line, barcode strip | Stacked sheets, folded corner |
| **Primary button** | Green fill, ink text | Orange fill, steel text, caps | Blue pill, white text |
| **LED "job waiting"** | Green blink | Orange blink | Blue blink |
| **Voice** | Plain, confident, warm | Terse, operational, caps states | Friendly, specific, a little dry |
| **Logo direction** | Sheet whose folded corner is a return arrow | Label with tear line + return arrow, stencil-cut | Just the folded corner, forming a small "r" |
| **Risk** | Could read as "generic SaaS-green" if executed lazily | Can feel cold; less at home in an office or kitchen | Can feel precious; harder to sell to a warehouse |

Files: `b-industrial/guidelines.html`, `c-stationery/guidelines.html` (open in a browser). Direction A is `../guidelines.html`.
